# End-user guide

## Connect

1. Click **Sign in with GitHub**. Review identity/email access and authorize.
2. Click **Connect repositories** and choose **Only select repositories** when you want the narrowest access.
3. Return to the app, refresh if needed, choose a connected repository, and click **Generate**.

You do not need a developer App, personal access token, or private key. An organization administrator may need to approve the installation.

## Generate and export

The service reads repository metadata and available stargazer avatars. Adjust preset and colors, preview, then download MP4 in the browser. Keep the tab open until encoding finishes.

Your own ability to push to a repository is not a permission granted to this App. You should never need to approve write permissions to generate a video.

## Manage access

Use **Manage access** on GitHub to add or remove repositories, then **Refresh** in the app. Signing out ends the local session; it does not uninstall the App.

## When avatars are unavailable

The star count may still be readable. The app will say so. You can explicitly choose **Create count-only video**, or fix installation/access and retry. Do not grant write access as a workaround.
